# Alita's | Mexican Restaurant

Site premium (cena 3D que reage ao scroll) para o Alita's, restaurante mexicano com 4 lojas em Moçambique.

- Instagram: https://www.instagram.com/alitasmz/
- Ficheiro único: `index.html` (three.js, GSAP + ScrollTrigger e Lenis por CDN)
- Logo redesenhado em SVG a partir da foto de perfil; ilustrações do menu desenhadas em canvas.
